EO1 Remote

Control your EO1 from anywhere through its GitHub gallery. At home the EO1's own control page is faster; this works from everywhere else.
  1. On GitHub: Settings › Developer settings › Fine-grained tokens › Generate new token.
  2. Repository access: only your gallery repository. Permissions: Contents: Read and write (and Actions: Read to see when GitHub has built it).
  3. Paste it here. It stays in this browser and is only sent to GitHub.
Changes are saved to GitHub; GitHub prepares them and the EO1 picks them up at its next check, usually within 5-10 minutes.
